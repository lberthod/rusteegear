# Guide du créateur — remplacé

Ce guide du 14 juillet 2026 décrivait un éditeur qui s'ouvrait « sur une scène
vide », se lançait avec `cargo run` et n'avait pas de capture d'écran. Il ne
correspond plus à l'interface (projet exemple, profil `dev-fast`, menus
actuels) et a été retiré le 4 septembre 2026 (roadmap post-audit UX, 4.3)
plutôt que laissé en contradiction avec les documents d'entrée.

Le chemin d'entrée est désormais unique :

1. **[QUICKSTART.md](../../QUICKSTART.md)** — lancer l'éditeur et jouer le
   projet exemple ;
2. **[FIRST_GAME.md](../FIRST_GAME.md)** — créer son premier objet animé ;
3. **[CONTROLS.md](../CONTROLS.md)** — tous les contrôles, clavier, souris,
   tactile, manette ;
4. **[MENTAL_MODEL.md](../MENTAL_MODEL.md)** — comment le moteur fonctionne.

L'historique du guide reste dans Git (`git log -- docs/guide-createur`).
